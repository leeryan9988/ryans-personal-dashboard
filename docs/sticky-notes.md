# 记事便签（2026-10-11）

## 范围

在现有看板增加独立板块，不迁移、不删除原有记录。参考 [PaperTodo](https://github.com/snownico0722/PaperTodo) 的纸张/待办使用方式，独立实现网页功能，没有复制其代码或美术资源。参考项目使用 PolyForm Noncommercial 许可，并非可无条件商业复用的 MIT 项目。

- 文字便签、基础安全 Markdown、清单及多行批量添加、勾选、关联便签。
- 清单默认按纵向逐条展示，可直接勾选和快捷添加；每条待办可设置北京时间截止时间，显示动态倒计时或逾期时间。
- 置顶、折叠、拖动/上下按钮排序、颜色、搜索、归档、回收站恢复。
- 图片选择/拖入/粘贴、私有签名地址、居中原图查看；8 张/便签、5 MB/张。
- Windows/手机浏览器响应式界面。不是 Windows 桌面悬浮窗，也不依赖原项目的桌面插件。
- 北京时间显示至分钟；创建/更新时间由数据库生成。

## 保存与安全

每条便签单独保存，700 ms 防抖，同步请求锁；新建同步锁防连续点击。未同步草稿按账号暂存在当前浏览器 localStorage，断网提示，重连/回到页面/60 秒重试。已经同步的完整资料以云端为准，未实现完整离线缓存。图片必须联网才能上传。

`version` 乐观锁防跨设备覆盖；请求 `mutation_id` 识别已成功但响应丢失的操作。冲突时不自动覆盖，可保留两份或明确放弃本机修改。待办尚未点击“添加”的输入会在关闭时提醒，不属于已保存项。

数据库 `sticky_notes` 开启 RLS，仅拥有者可读写；无匿名读取/永久删除权限。`sticky-images` 为私有桶，用户只能写入和读取自己的 UID 目录。删除便签是软删除；移除附件不会立即物理删除云端文件，避免破坏副本或恢复，仍占用存储额度。暂无自动清理。

新增数据若需备份，应同时导出 `sticky_notes` 和 `sticky-images` 对象；现有每月备份任务未由本功能创建或变更。Notion 周复盘同步未包含便签。

## 故障记录与复用方案

1. 沙箱内无头 Edge 启动失败；提升执行环境后又无法访问沙箱内的测试服务器。原因是进程/端口隔离，不是账户或站点故障。有效方案：测试启动自己的服务器和独立无头 Edge，处于同一环境，禁用该测试浏览器系统代理；不修改系统代理、Git 配置或用户浏览器。
2. Vite 开发扫描不能解析 `@/`，而现有静态构建能成功。测试专用配置显式设置 alias；不扩大修改正式发布配置。
3. Supabase 安全建议显示原有 `set_updated_at` search_path、`rls_auto_enable` 函数执行权限及泄露密码保护警告；新表/新函数没有对应告警。遵循最小影响原则，未更改这些既有配置。参考官方数据库检查说明：https://supabase.com/docs/guides/database/database-linter 。
